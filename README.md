# Fit the ReN

Jeu de placement : empilez les charges électriques (véhicule électrique, chauffage, électroménager) heure par heure pour qu'elles tiennent sous un profil de production photovoltaïque.

- 10 scénarios météo (été, hiver, orage, giboulées…) avec tirages aléatoires
- Solveur exact (programmation dynamique) qui calcule le meilleur placement possible
- Fonctionne entièrement dans le navigateur, un seul fichier `index.html`

Jouer : ouvrez `index.html` dans un navigateur, ou la version publiée sur GitHub Pages.
